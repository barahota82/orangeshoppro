0) سياسة GL الحالية — مغلقة (GAP-ACC-14 — للوكلاء: لا تسأل المالك عن الطابور)
================================================================================

ARABIC
- **حفظ = ترحيل GL فوري → التقارير فوراً** (ميزان، P&L، كشف حساب، ذمم).
- **إقفال التعديلات (`edit_lock`):** **رقابة فقط** — منع تعديل/حذف بعد قفل المسؤول — **لا يؤخّر** التقارير و**ليس** شرط ظهورها.
- **`gl_posting`:** redirect → **`edit_lock`** — **ليس** «انتظر ترحيل للتقارير».
- **طابور GL (`orange_gl_pending_movements`):** **legacy opt-in فقط** — `ORANGE_GL_USE_PENDING_QUEUE` في `.env.php` (**افتراضي off** على السيرفر).
- **Lane B (افتراضي):** مشتريات، سندات، YEC §9، §13 «إنشاء القيود»، INV-C — **خارج** gl_posting.
- **Lane C:** `completed` مخزون بلا GL؛ GL لاحقاً من Lane B.
- مرجع canonical: **`docs/archive/ORANGE_EDIT_LOCK_POLICY.txt`**

ENGLISH
- Save → immediate posted vouchers in reports; edit_lock = edit control only; GL pending queue legacy opt-in.

PURPOSE
- مرجع واحد لحالة **قائمة «الحسابات والتقارير»** في الأدمن + مسار GL + التقارير المرتبطة.
- للوكلاء والمالك عند «كمّل المحاسبة» أو «أغلق الثغرات» — **قبل** توسيع نطاق جديد.
- **لا يغني** عن: ORANGE_GL_MOVEMENTS_AND_POSTING_POLICY.txt، ORANGE_ACCOUNTING_MAPPING_AND_REPORT_HANDOFF.txt، docs/ACCOUNTING_REPORTING_POLICY_V2.md، ORANGE_PROJECT_COMPLETION_ROADMAP.txt (مراحل 3–6).
