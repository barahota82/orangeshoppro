# Orange — Disaster Recovery Production Certification (Phase 3B.4G)

## Purpose

This document records the **non-production** Disaster Recovery (DR) drill used to certify the Orange **Full Restore** lifecycle. It does **not** authorize Country production restore.

Machine-readable companion: `docs/backup/restore_dr_certification_report.json` (generated by the drill CLI).

## Hard rules

- The drill **must not** wipe the real production database.
- The drill **must not** rename real production uploads.
- The drill **must not** enable real production maintenance.
- The drill **must not** mutate real `.env.php` or invoke live payment/email/SMS/webhook integrations.
- Country production restore remains **uncertified** (`country_restore_certified = false`).

## How to run

```text
php scripts/backup/run_restore_dr_drill.php --mode=all
php scripts/backup/run_restore_certification_tests.php
```

Allowed modes: `success` | `rollback` | `all` (default `all`). Optional: `--verbose`.

No arbitrary paths, DB names, or package paths are accepted.

## Isolation guarantees

| Fence | Requirement |
|-------|-------------|
| Marker | `.orange_restore_dr_drill_fixture` on session/backup/work/fixture roots |
| Fixture prod DB | `orange_dr_fixture_prod` (never `orange_db`) |
| Fixture shadow DB | `orange_dr_fixture_shadow` |
| Uploads / backup roots | Temporary session directories under the OS temp dir |
| Destructive adapters | Require drill context + markers; fail closed otherwise |
| Failure injection | Drill registry only — never env/HTTP flags |

## Certification thresholds

Full Restore may be marked certified **only** when all of the following hold:

1. Success drill passes through `restore_completed` (C0–C8, final report, locks/maint released, anchor/pin/forensics preserved).
2. Rollback drill passes through `rollback_completed` (C9–C12, fixture DB/uploads restored, maint released only after finalize).
3. All mandatory failure injections fail closed safely.
4. Production isolation proven.
5. No critical/high open blockers remain.
6. Server-side certification self-test master runner passes.

Otherwise recommendation is `CONDITIONAL` or `NOT_CERTIFIED`. Unit-test green alone is **not** enough for `CERTIFIED`.

## Expected honest outcome (current stack)

With storefront/admin maintenance middleware still pending (phase 3B.4H) and DB steps exercised via isolated mock PDO adapters, the typical recommendation is:

`production_execution_recommendation = CONDITIONAL`  
`full_restore_certified = false`  
`country_restore_certified = false`

## Operator actions before any live window

1. Review `open_blockers` in the JSON report.
2. Complete maintenance middleware wiring (3B.4H).
3. Re-run the drill on a production **clone** host with real MySQL fixtures when ready.
4. Keep Country production restore disabled.
5. Follow `ORANGE_DR_OPERATOR_RUNBOOK.md`.
